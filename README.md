# eulji — 모듈러 미드센추리

알루미늄 프로파일 가구를 원하는 치수로 설계하고, 을지로 소공인이 제작하는 웹서비스의 프로토타입입니다.

**[→ 데모 보기](https://wjwjw-www.github.io/eulji/)**

---

## 무엇을 푸는가

| 문제 | 이 프로토타입의 대응 |
|---|---|
| 미드센추리·프로파일 가구가 시장에서 과도하게 비싸다 | 설계 중에 **부품표와 원가 분해를 전부 공개**한다 |
| 산 가구가 방에 안 맞는다 | 벽 치수를 넣으면 **10mm 단위로 맞춘다** |
| 을지로 제조업이 무너지고 있다 | 주문을 **절단 리스트·작업지시서로 변환**해 소공인에게 넘긴다 |

## 화면

- `index.html` — 랜딩. 히어로 이미지는 Blender로 렌더했고 데스크톱(가로)·모바일(세로) 두 컷을 아트디렉션해 따로 씁니다.
- `build.html` — 컨피규레이터. 아래 기능이 실제로 동작합니다.

## 동작하는 기능

**3D**
- 2020 / 2040 / 3030 T슬롯 단면을 **런타임에 생성**합니다. 모델 파일이 없습니다 — 단면은 같고 길이만 다르므로, 파일로 관리하면 조합이 폭발합니다.
- 궤도 회전·줌·팬, 정면/측면/평면/아이소 전환, 치수선, 바닥 격자, 분해도
- 패널을 클릭해 선택 → 그 칸만 비우기

**설계**
- W/D/H 슬라이더 (10mm 스냅), 칸 수·단 수, 프레임 규격·마감, 면재 4종
- 간편 모드(단 높이 균등) ⇄ 자유 모드(단별 높이 개별 지정)
- 내 방 치수 입력 → 최대 치수 자동 조정
- Undo/Redo (⌘Z / ⇧⌘Z), 자동 임시저장, 링크 공유

**규칙 엔진 (R1–R9)**
| 규칙 | 내용 | 근거 |
|---|---|---|
| R1 | 절단 길이 ≥ 30mm | 가공 설비 한계 |
| R2 | 10mm 그리드 스냅 | 조합 폭발 억제 |
| R3 | 처짐 `D = L³W/(48EI)` | 80/20 문서, 6063-T5 E=68,900 N/mm² |
| R4 | 체결부 강도 | 강한 프로파일 + 약한 브래킷 조합 경고 |
| R5 | 풀아웃 7.2kN/체결 | Vention 설계 가이드 |
| R6 | 전도 위험 (높이/깊이 비) | 안전 |
| R7 | 패널 무지지 스팬 | 목재 처짐 |
| R8 | 총 중량 → 분할 배송 | 물류 |
| R9 | 원장 수율 — 치수를 조정하면 저렴해짐 | 네스팅 |

경고는 모달로 막지 않고 배너로 띄우며, **원클릭 해결 버튼**이 붙습니다. 차단(Error)일 때만 장바구니를 잠급니다.

**견적·주문**
- 실시간 가격, 자재/가공/포장/배송 분해, 부품표 전체 공개, CSV 내려받기
- 전자상거래법 제17조 제2항 제6호에 맞춘 **치수 재확인 + 2단 동의** 플로우
- **작업지시서 A4 출력** — 절단 리스트, 패널 재단, 부자재, 공차, 원장 손실

## 아직 없는 것

- **결제와 백오피스.** 서버가 필요합니다. 장바구니는 동의 기록과 함께 브라우저에만 쌓이고 멈춥니다.
- **칸별 소재.** 소재는 아직 전역 값이라 모든 패널에 함께 적용됩니다.
- **레고식 자유 조립.** 자유 모드는 단별 높이까지만 열려 있습니다. 자유도 경계는 실주문 치수 분포를 보고 정해야 합니다.
- **서버 가격 재계산.** 지금은 클라이언트 계산값이 그대로 보입니다. 결제를 붙이면 반드시 서버에서 다시 계산해야 합니다.

## ⚠ 단가는 전부 추정치입니다

`assets/core.js` 상단의 자재·가공 단가는 공개 자료로 잡은 **추정치**이고 실제 을지로 견적이 아닙니다. 그대로 사업 판단에 쓰면 안 됩니다.

## 구조

```
index.html          랜딩
build.html          컨피규레이터
assets/
  core.js           단면·부재생성·규칙엔진·견적 — DOM/Three.js 의존 없는 순수 로직
  core.test.mjs     자가검증
  app.js            Three.js 씬 + UI 연결
  build.css
  hero-*.webp       Blender 렌더
```

`core.js`를 분리해 둔 이유: 가격 계산이 클라이언트와 서버에서 어긋나면 안 되므로, 서버를 붙일 때 같은 파일을 그대로 가져다 씁니다.

## 실행

정적 파일이지만 ES 모듈을 쓰므로 `file://` 로는 열리지 않습니다.

```bash
python3 -m http.server 4173
```

테스트:

```bash
node assets/core.test.mjs
```

의존성 설치는 없습니다. Three.js는 CDN에서 버전 고정으로 가져옵니다.
